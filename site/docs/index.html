    Connect your AI

    Shop owners: create a key in Settings, then point Cursor or Claude Desktop at your shop. Vendors use the same key against the same host.

    Sign in at app.odapm.ai. Your shop is https://YOUR-SHOP.odapm.ai in production, or https://stg.odapm.ai in staging. MCP and the HTTP API live on that shop origin — not on this marketing site. They ship with the tenant app; a given shop may not have them on yet.

    • Get a key

      Settings → API access. Name the key, create, copy the token once.

    • Cursor

      Point Cursor at https://YOUR-SHOP.odapm.ai/mcp with a Bearer token.

    • Claude Desktop

      mcp-remote in claude_desktop_config.json. Not Connectors.

    • HTTP API

      Bearer token against the shop origin. The Worker owns prices — do not send cents.

    • Internal agent

      Settings → Internal agent. Default off. Off means off.
