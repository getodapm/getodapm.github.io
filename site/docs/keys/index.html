    Get a key

    1. Sign in at app.odapm.ai (or your shop host).
    2. Open Settings (owner/admin).
    3. Open API access.
    4. Name the key. Click MCP starter set unless you know you want fewer scopes. Create.
    5. Copy the token now — it is shown once. Store it in a password manager.

    The starter set checks catalog, customers, properties, jobs, and quotes (read, write, price, and PDF). Execute is not in the starter set. After you leave the page you will only see the last four characters. Tokens look like odapm_live_… or odapm_test_….
