# Agent rules — ODAPM

This repo is the open ODAPM standard (schema, methodology, prompts, tools). It is not the estimating app and not an operator pack.

- Any assistant that can read this folder and write `model.json` / `tax.json`.
- Prompts in `prompts/` run in order, starting at `00-START-HERE.md`.
- Never paste proprietary pricing lists. Cite open sources in each item's `basis`.
